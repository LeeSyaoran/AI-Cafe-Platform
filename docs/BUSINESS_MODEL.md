# AI Café - Business Model

## Revenue Streams

```
                    REVENUE
                       │
    ┌──────────────────┼──────────────────┐
    │                  │                  │
 Drinks           Membership          Pass
    │                  │                  │
    │                   │            Prepaid Drinks
    │                   │
    │            Developer API
    └──────────────────┴──────────────────┘
```

### Primary Revenue Sources

1. **Đồ uống** - Core revenue ban đầu
2. **AI upgrade** - Upsell từ đồ uống
3. **Membership** - Monthly subscription
4. **Drink Pass** - Prepaid bundles
5. **Developer/API** - Future revenue stream

## Key Insight

AI không nhất thiết phải là sản phẩm bán đứt lập từ đầu.

> AI là giá trị gia tăng giúp tăng giá trị đơn hàng và tần suất quay lại.

## Customer Value Proposition

| Traditional | AI Café |
|-------------|---------|
| Đăng ký nhiều AI provider | Mua đồ uống |
| Tự quản lý API key | Nhận AI Credits |
| Mua nhiều subscription | Đăng nhập AI Café |
| Tìm model phù hợp | Chọn nhiệm vụ |

## Operating Contribution

```
Revenue
- Drink Variable Cost
- Actual AI Cost
- Fixed Cost
= Operating Contribution
```
