#### Android App

| Thành phần | Mô tả |
|------------|--------|
| **Ngôn ngữ** | Kotlin 1.9+ |
| **UI Framework** | Jetpack Compose (primary) |
| **Minimum Android** | API 24 (Android 7.0) |
| **Target SDK** | API 34 (Android 14) |
| **Architecture** | MVVM + Clean Architecture |
| **DI** | Hilt |

**Tính năng chính:** (Giống iOS)
- AI Chat với streaming
- Mua credits & membership
- Ví điện tử
- Lịch sử giao dịch
- Thông báo push

#### Web App (Customer)

| Thành phần | Mô tả |
|------------|--------|
| **Framework** | Next.js 14 (App Router) |
| **Language** | TypeScript 5.x |
| **UI Library** | Tailwind CSS + Radix UI |
| **State** | Zustand + React Query |
| **Auth** | NextAuth.js |

**Routes:**
```
/
├── (auth)
│   ├── /login              # Đăng nhập OTP
│   └── /register           # Đăng ký
├── (main)
│   ├── /chat              # AI Chat interface
│   ├── /chat/[id]         # Chat session
│   ├── /workspace          # Collaborative workspace
│   ├── /pricing           # Bảng giá
│   ├── /purchase           # Mua credits
│   ├── /membership         # Membership
│   ├── /wallet             # Ví & số dư
│   ├── /history            # Lịch sử
│   └── /settings           # Cài đặt
```

#### Dashboard Modules

| Module | Mô tả | Tính năng chính |
|--------|--------|------------------|

| **Orders** | Quản lý đơn | List, details, refund, export |
| **Credits** | Quản lý credit | Adjust, history, bulk operations |

| **Analytics** | Báo cáo | Revenue, usage, trends |
| **Settings** | Cấu hình | System, payment, AI models |
| **Audit Logs** | Nhật ký | All admin actions |
