☕ AI CAFE PLATFORM - API DOCUMENTATION

Base URL: https://api-staging.aicafe.vn/api

Production: https://api.aicafe.vn/api

Local: http://localhost:3000/api

1. AUTHENTICATION

POST/v1/auth/send-otp

Send OTP to phone or email

Body:

{ "email": "test@example.com", "phone": "0909123456", "type": "register" }

POST/v1/auth/verify-otp

Verify OTP and get tokens

Body:

{ "email": "test@example.com", "phone": "0909123456", "otp": "123456" }

POST/v1/auth/register

Register new user account

Body:

{ "email": "test@example.com", "password": "password123", "phone": "0909123456" }

POST/v1/auth/login

Login with email and password

Body:

{ "email": "test@example.com", "password": "password123" }

POST/v1/auth/refresh

Refresh access token

Body:

{ "refreshToken": "{{refreshToken}}" }

POST/v1/auth/logout

Logout and invalidate token

Body:

{ "refreshToken": "{{refreshToken}}" }

2. USER PROFILE

GET/v1/me

Get current user profile

Headers:

Authorization: Bearer {{accessToken}} X-User-ID: {{userId}}

PUT/v1/me

Update current user profile

Headers:

Authorization: Bearer {{accessToken}} X-User-ID: {{userId}}

Body:

{ "fullName": "Nguyen Van Test", "displayName": "TestUser", "dateOfBirth": "1990-01-15", "gender": "male" }

GET/v1/users/{id}

Get user by ID

3. CART

GET/v1/cart?cafeId={UUID}

Get user cart for a cafe

Headers:

Authorization: Bearer {{accessToken}} X-User-ID: {{userId}}

POST/v1/cart/items

Add item to cart

Headers:

Authorization: Bearer {{accessToken}} X-User-ID: {{userId}}

Body:

{ "cafeId": "REPLACE_WITH_CAFE_ID", "productId": "REPLACE_WITH_PRODUCT_ID", "variantId": null, "quantity": 1, "options": {}, "modifiers": [], "notes": "" }

PUT/v1/cart/items/{id}

Update cart item

Body:

{ "quantity": 2, "notes": "Extra ice" }

DELETE/v1/cart/items/{id}

Remove item from cart

DELETE/v1/cart?cafeId={UUID}

Clear all items from cart

4. ORDERS

POST/v1/orders

Create new order from cart

Body:

{ "companyId": "REPLACE_WITH_COMPANY_ID", "cafeId": "REPLACE_WITH_CAFE_ID", "orderType": "pickup", "customerNote": "", "promoCode": "" }

GET/v1/orders?page=0&size=20

Get user order history

GET/v1/orders/{id}

Get order by ID

GET/v1/orders/number/{orderNumber}

Get order by order number

PUT/v1/orders/{id}/confirm

Staff confirms order

PUT/v1/orders/{id}/preparing

Staff starts preparing order

PUT/v1/orders/{id}/ready

Staff marks order as ready

PUT/v1/orders/{id}/complete

Staff completes order

POST/v1/orders/{id}/cancel

Cancel order

Body:

{ "reason": "Customer requested cancellation" }

5. PAYMENTS

GET/v1/payments/methods

Get available payment methods

POST/v1/payments

Create payment for order

Body:

{ "orderId": "REPLACE_WITH_ORDER_ID", "companyId": "REPLACE_WITH_COMPANY_ID", "amount": 50000, "paymentMethod": "CREDIT", "returnUrl": "https://aicafe.vn/payment/return" }

GET/v1/payments/{id}

Get payment by ID

GET/v1/payments/order/{orderId}

Get payment by order ID

POST/v1/payments/{id}/cancel

Cancel pending payment
